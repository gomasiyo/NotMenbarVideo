# YouTube Member-Only Hider

YouTubeのチャンネルページや検索結果などに表示されるメンバー限定の動画やコンテンツを自動的に非表示にするChrome拡張機能です。

## 概要

この拡張機能は、YouTubeの閲覧中にメンバーシップ限定のコンテンツ（動画、コメントなど）を検出し、DOMから削除することで、より快適なブラウジング体験を提供します。

## 主な機能

- **動画リストからの非表示**: チャンネルの動画タブ、登録チャンネルフィード、検索結果などからメンバー限定動画を非表示にします。
- **動画再生ページのオーバーレイ削除**: 「この動画はメンバー限定です」といった再生画面のオーバーレイを削除します。
- **コメント欄の非表示**: メンバー限定のコメント欄を非表示にします。
- **動的読み込み対応**: YouTubeの無限スクロールなどで動的に読み込まれるコンテンツにも対応しています。

## 仕組み

この拡張機能は、YouTubeのページに`content.js`を挿入します。このスクリプトは、ページ内に「メンバー限定」や「Members only」といったキーワードが含まれる特定の要素を監視します。

対象の要素が見つかると、その要素（動画コンテナやコメントブロックなど）をDOMから削除します。`MutationObserver` APIを利用して、ページの動的な変更（新しい動画の読み込みなど）を検知し、継続的に処理を実行します。

## インストール方法

この拡張機能はChromeウェブストアで公開されていません。以下の手順で手動でインストールしてください。

1.  このリポジトリをダウンロードまたはクローンします。
2.  Chromeブラウザで、アドレスバーに `chrome://extensions` と入力して拡張機能管理ページを開きます。
3.  ページの右上にある「**デベロッパーモード**」をオンにします。
4.  「**パッケージ化されていない拡張機能を読み込む**」ボタンをクリックします。
5.  ダウンロードしたリポジトリのフォルダを選択します。
6.  拡張機能がインストールされ、有効になります。

## 注意事項

YouTubeのサイト構造が変更された場合、この拡張機能が正常に動作しなくなる可能性があります。
